Garpix Practice 2026 – Анализ неопределённости в системе Garpix Load System

О проекте
Данный репозиторий содержит результаты и код, разработанный в рамках производственной практики в продуктовом подразделении Garpix Load System ООО "Гарпикс" (НИТУ МИСИС, группа БПМ-23-РК-1, лето 2026).

Цель работы: исследовать, как погрешности в измерении размеров и массы грузов влияют на итоговую эффективность загрузки грузового пространства, оцениваемую метрикой fill_rate (процент заполнения). Реализованы и протестированы методы пересборки (resampling) для оптимизации размещения грузов.

Ключевые результаты
Метод	Улучшение
Паллетизация	Количество паллет ↓ 33% (12 → 8)
Пересборка (±3%)	fill_rate ↑ +0.43 п.п. (22.09% → 22.52%)
Выбор транспорта	Определение оптимального ТС
Выявлена критическая ошибка в исходных данных: масса указана в граммах вместо килограммов (завышение в 905 раз).

1) Установка и запуск
Клонирование репозитория
Установка зависимостей
bash
pip install -r requirements.txt
Запуск основного скрипта
bash
python GLS_without_API_integration.py
Запуск сравнения методов пересборки
bash
python compare_resampling_methods.py

2) Методы пересборки (Resampling)
Метод	Описание
Без пересборки	Базовый расчёт по исходным данным
Паллетизация	Группировка грузов в паллеты 1200×800×1800 мм
Выбор транспорта	Автоматический подбор оптимального ТС
Вариация размеров	Многократные запуски с изменением размеров на ±3% (10 итераций)
API GLS	Интеграция с системой GLS для получения точного fill_rate
Симуляция ошибок	5 сценариев ошибок измерения
