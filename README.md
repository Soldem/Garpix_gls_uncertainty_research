# Garpix_gls_uncertainty_research
Анализ влияния неопределённости входных данных на эффективность работы системы «Garpix Load System». Реализованы методы пересборки (resampling) для оптимизации загрузки грузового пространства: паллетизация, выбор транспорта, вариация размеров грузов, интеграция с API GLS.
